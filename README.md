# Casa Bacurau — site estático

Site de uma página sobre a **Casa Bacurau**, bar/casa de eventos em Santo Amaro, Recife/PE
(karaokê, DJs, torneio de FIFA, liga de dominó). Feito com HTML e CSS puros, sem build step,
para publicação no GitHub Pages.

Site não-oficial, feito com base em informações públicas do [Instagram](https://www.instagram.com/casabacurau/)
e do Google.

## Publicar no GitHub Pages

Settings → Pages → Branch: `main` / `root`.
